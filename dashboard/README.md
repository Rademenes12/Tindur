# Tindur Org Dashboard

System zarządzania organizacjami Tindur, umożliwiający administrację użytkownikami, monitorowanie płatności oraz zarządzanie kalendarzem wydarzeń. Platforma zapewnia pełną kontrolę nad procesami subskrypcyjnymi i operacyjnymi w czasie rzeczywistym.

## Stack
- **Next.js 15** (App Router)
- **TypeScript** (strict mode)
- **Supabase** (Auth, Database, Storage)
- **Stripe Connect** (płatności i rozliczenia)
- **Tailwind v4** (styling)
- **React Hook Form + Zod** (walidacja formularzy)
- **FullCalendar** (widok kalendarza)
